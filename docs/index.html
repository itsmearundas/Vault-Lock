Encrypted, not just hidden
Every file is AES-256-CTR + HMAC-SHA256 encrypted before it touches the vault. File and folder names become random tokens on disk — the real names live only in an encrypted manifest.
Decoy and panic-wipe passwords
A second password opens a decoy vault built on a separate key. A third silently wipes the real vault with no error shown — no trace it happened.
Your choice of drive
Store the vault on your C: drive, a second internal drive, an external SSD, or a NAS mount — movable later without losing anything.
